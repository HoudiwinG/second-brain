# Журнал архитектурных решений (ADR)

Формат записи. Одна запись = одно критическое решение/изменение.

---

## ADR-<номер>: <краткое название>
- **Дата (UTC):** YYYY-MM-DD HH:MM
- **Этап:** stage-XX
- **Тип:** architecture | schema | api | dependency | integration | security | ux | refactor
- **Автор/агент:** agent-1 / <имя LLM> (или человек)
- **Статус:** proposed | accepted | superseded by ADR-N | deprecated

### Контекст
Что требовалось решить, какие ограничения.

### Решение
Что именно сделано/выбрано.

### Альтернативы
Какие варианты рассматривались и почему отвергнуты.

- Отрицательные/риски:
- Влияние на совместимость/миграции:
