## Находки

### [MAJOR] S05-001 — обучение не входит в JSON-бэкап

- **Категория:** C/F — данные/документация.
- **Где:** `lib/data/backup/backup_service.dart:16-19,171-281,315-326,
  329-340`; ARB `settingsDataHint`/`importWarning`; ADR-014.
- **Что не так:** `_buildBackup()` не содержит `learning_tracks`/
  `learning_sessions`; `_validateHeader()` не требует их; `_clearAll()` не
  удаляет. UI обещает «полный бэкап» и «замену всех локальных данных».
- **Ожидаемое:** новые сущности экспортируются/восстанавливаются/очищаются
  либо явно исключаются в ADR и UI.
- **Исправление:** версия формата 2, необязательные для v1 массивы
  `learning_tracks`/`learning_sessions`, импорт в порядке трек → сессия,
  очистка в `_clearAll`, round-trip-тест.
- **Источники:** S05-A-001, S05-B-001.
- **Статус:** open (исправление — в `stage-05-fix-results.md`).

### [MINOR] S05-002 — приватность `generateRoadmap` только на уровне UI

- **Где:** `learning_trainer.dart:27-54`; `learning_screen.dart:761`.
- **Что не так:** `generateRoadmap(String goal)` не проверяет
  `isPrivateForLlm`; кнопка отключается только в UI. `suggestMaterials`/
  `checkIn` защищены.
- **Исправление:** принимать `LearningTrack`, fail-closed до сети, тест на
  приватный roadmap.
- **Источники:** S05-A-007, S05-B-002.

### [MINOR] S05-003 — сохранение AI-roadmap не ожидается

- **Где:** `learning_screen.dart:526-554`.
- **Что не так:** `result.when(success: async { ... })` не ожидается,
  `_aiBusy` снимается до `setSteps`, ошибки сохранения не перехватываются;
  edit/delete доступны во время AI-запроса.
- **Исправление:** `await` сохранения, `try/catch`, блокировка действий.

### [MINOR] S05-004 — read-modify-write и целостность шагов

- **Где:** `learning_repository.dart:118-177,233-240,293-324`.
- **Что не так:** `setStepStatus` без транзакции; `softDeleteTrack`
  неидемпотентен; `deleteSession` не обновляет `updated_at` и успешен для
  несуществующей сессии; `fromJson` без id генерирует новый id при каждом
  чтении; возможна коллизия synthetic id.
- **Исправление:** транзакция, идемпотентный soft-delete, проверка сессии,
  stable fallback id, уникальные id.

### [MINOR] S05-005 — дата сессии как момент времени

- **Где:** `learning_repository.dart:217`; `learning_session.dart:20-22`;
  `learning_screen.dart:950-952,1106`.
- **Что не так:** дата сохраняется как UTC-инстант и отображается через
  `toLocal()`, поэтому при смене TZ может сдвинуться на день.
- **Исправление:** хранить UTC-полночь календарной даты и отображать без
  пересчёта TZ; тест.

### [MINOR] S05-006 — нельзя редактировать/удалять шаги

- **Где:** `learning_screen.dart:823-899`.
- **Что не так:** шаг можно добавить и сменить статус, но не изменить/
  удалить/переупорядочить.
- **Исправление:** edit/delete через `setSteps`, ARB, тесты.

### [MINOR] S05-007 — тесты не покрывают error/corruption/UI-сценарии

- **Где:** `test/learning_*`, `test/db_migration_test.dart`.
- **Что не так:** нет `updateTrack`, битого JSON, границ, отсутствующего
  ключа, invalid/raw JSON roadmap, приватного checkIn, большинства UI-
  действий; v5→v7 не удаляет learning-таблицы и не доказывает их создание;
  v6→v7 не проверяет все индексы/FK.
- **Исправление:** добавить тесты, усилить миграционные проверки.

### [MINOR] S05-008 — локализация/единицы/подписи

- **Где:** ARB, `learning_screen.dart:950-952,1070-1075,526-530`,
  `learning_trainer.dart`.
- **Что не так:** «30 Минуты» вместо «30 мин»; русские ошибки/промпты при
  EN-UI; мёртвые error-ключи; кнопка замены «Сохранить»; ошибка диапазона
  сессии как «обязательное поле».
- **Исправление:** отдельные ключи минут/ошибок/«Заменить», корректные
  подписи; AI-язык задокументировать как ограничение.

### [MINOR] S05-009 — устаревшая документация/TD

- **Где:** `docs/tech-debt.md:479-490`, `docs/context.md:361-362`,

- **Что не так:** TD-22 утверждает, что learning-таблиц нет; ADR-022

  переоценивает тесты и неточно описывает check-in/контекст.
- **Исправление:** обновить TD-22, ADR-022, отчёт и context.

### [NIT] S05-010 — комментарий схемы и доступность

- **Где:** `app_database.dart:299-303`; `learning_screen.dart:178-179,191`.
- **Что не так:** комментарий аудита стоит над `LearningTracks`; нет
  tooltip/semantics у privacy-иконки и прогресса.
- **Исправление:** переместить комментарий, добавить semantics/tooltip.

### [NIT] S05-011 — мелкие UI/парсер/индекс

- **Где:** `learning_trainer.dart:171-179` (`lastIndexOf(']')`),
  `app_database.dart` (нет индекса deleted_at), `learning_screen.dart`
  (custom fields `key=value`, диапазон длительности).
- **Что не так:** хвостовой `]` ломает парсер; нет индекса soft-delete;
  многострочные custom fields теряются; диапазон длительности показывает
  неверное сообщение.
- **Исправление:** сбалансированный парсер, индекс `deleted_at/updated_at`,
  валидация полей, отдельный ARB-ключ.
