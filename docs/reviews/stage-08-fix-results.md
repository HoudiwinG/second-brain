## Блокеры

### S08-A-001 / S08-B-001 — фильтры после LIMIT

- **Исправление:** `entity_type IN (...)` перенесён в SQL до `LIMIT`; при
  фильтре даты FTS-выборка не обрезается (`LIMIT -1`), дата фильтруется
  после и только затем применяется пользовательский лимит.
- **Тест:** «фильтр типа не теряется после SQL LIMIT» (60 заметок + письмо).
- **Файлы:** `search_repository.dart`.

### S08-A-002 / S08-B-002 — backfill индекса

- **Исправление:** `search.index.version` в `app_settings`;
  `ensureSearchIndexVersion` вызывается в `appDatabaseProvider` и при
  несовпадении делает `rebuildSearchIndex`, покрывающий learning/chat/mail.
- **Тест:** «backfill переиндексирует существующую БД».
- **Файлы:** `search_index.dart`, `di.dart`.

### S08-B-003 — валюты аналитики

- **Исправление:** экран передаёт `currency: RUB`; `buildAnalyticsSummary`
  принимает `currency`, фильтрует удалённые операции и чужие валюты.
- **Тест:** RUB + USD, проверяется, что USD не входит в суммы.
- **Документация:** аналитика явно RUB-only.

### S08-B-004 — лимит писем

- **Исправление:** `MailRepository.countMessages()` (`COUNT(*)`), аналитика
  использует его вместо `listMessages(limit: 1000)`.
- **Тест:** count + privacy.
