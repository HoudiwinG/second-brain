Хронологический журнал находок ревьюера и их закрытия.

| Timestamp (UTC) | Этап | ID      | Действие  | Кто     | Коммит | Примечание |
|-----------------|------|---------|-----------|---------|--------|------------|
| 2026-10-21 17:40| 0    | R00-000 | найдено   | agent-1 | -      | n/a        |

Примечание к этапу 0: журнал дебаг- находок журналируется агентом-ревьюером. Агент-1
исправлял собственные ошибки сборки в процессе разработки:

| Timestamp (UTC) | Проблема                                        | Решение                          |
|-----------------|--------------------------------------------------|----------------------------------|
| 2026-10-21 18:35| `AppLocalizations.of()` nullable в Flutter 3.47  | `!` в точках вызова              |
| 2026-10-21 18:50| tray_manager 0.8 требует C-тулчейн даже в тестах | пин 0.5.0 (ADR-006)              |
| 2026-10-21 19:05| DateTime из drift возвращается в локальной зоне  | сравнение через toUtc()          |
| 2026-10-21 19:20| riverpod 3: нет `valueOrNull`                    | nullable `value`                 |

## Паттерны ошибок

Обновляется в конце каждого ревью. Список повторяющихся классов ошибок
и предложения по улучшению промпта/архитектуры.

- Валидация API пакетов перед написанием кода. Big-version-мутации (riverpod 3,
  drift 2.35, tray_manager 0.8, flutter 3.47) сломали 4 контрактом в ходе этапа.
  Рекомендация: при первом применении пакета — читать его доки/примеры в pub-кэше
  до написания вызовов.
